# Plumber Service Boise - Professional Website

A beautiful, modern, and responsive website for Plumber Service Boise, showcasing professional plumbing services in the Boise area.

## Features

### 🎨 Design
- **Modern & Professional**: Clean, contemporary design with gradient backgrounds
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices
- **Beautiful Animations**: Smooth scroll effects, hover animations, and entrance transitions
- **Accessibility**: Semantic HTML and keyboard-friendly navigation

### 📱 Sections
1. **Navigation Bar** - Sticky navigation with smooth scrolling
2. **Hero Section** - Eye-catching banner with call-to-action buttons
3. **Services Section** - 6 core plumbing services with icons
4. **Why Choose Us** - 6 key differentiators with numbered features
5. **Testimonials** - Customer reviews with 5-star ratings
6. **About Us** - Company information with impressive statistics
7. **Contact Section** - Contact form and service area information
8. **Footer** - Links and copyright information

### 🔧 Services Included
- Emergency Repairs
- Drain Cleaning
- Leak Detection
- Water Heater Service
- Sewer Repair
- Repiping

### ✨ Interactive Elements
- Smooth scrolling navigation
- Contact form with validation
- Animated counters for statistics
- Scroll-triggered animations
- Hover effects on cards and buttons
- Mobile-friendly responsive design

## GitHub Pages Setup

This website is ready to be deployed on GitHub Pages:

1. Go to repository Settings
2. Scroll to **Pages** section
3. Set source to `main` branch
4. Your site will be live at `https://seoplumbing80-pixel.github.io/Plumber-Service-Boise`

## Customization

### Phone Number
Replace `(208) 555-PLUMBER` with your actual phone number in:
- Navigation bar
- Contact section
- Any phone link

### Business Information
Update the following in `index.html`:
- Company name
- Service area
- Hours of operation
- Team information

### Colors
Modify CSS variables in `styles.css`:
```css
:root {
    --primary-color: #0066cc;
    --secondary-color: #00a3e0;
    --accent-color: #ff6b35;
    /* ... etc */
}
```
